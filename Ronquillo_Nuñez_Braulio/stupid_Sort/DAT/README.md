## Stupid Sort

Esta carpeta contiene los casos de prueba y las salidas generadas para el algoritmo de `stupid sort`.

### Archivos

- `caso1.txt`: primer caso de prueba.
- `output_caso1.txt`: salida obtenida al ejecutar el algoritmo con `caso1.txt`.
- `caso2.txt`: segundo caso de prueba.
- `output_caso2.txt`: salida obtenida al ejecutar el algoritmo con `caso2.txt`.

### Ejecucion

Desde la raiz del proyecto:

```powershell
Get-Content stupid_Sort\DAT\caso1.txt | python stupid_Sort\SRC\gnome.py
Get-Content stupid_Sort\DAT\caso2.txt | python stupid_Sort\SRC\gnome.py
```

Las salidas guardadas en esta carpeta fueron generadas con esos comandos.
