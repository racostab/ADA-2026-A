**✅ Implementación del Algoritmo Comb Sort en Python**

### Explicación del Algoritmo

**Comb Sort** (Ordenamiento de Peine) es una mejora del **Bubble Sort**. Su idea principal es eliminar la ineficiencia del Bubble Sort al comparar elementos que están separados por una **brecha (gap)** grande al principio, y luego ir reduciendo esa brecha progresivamente.

En lugar de comparar solo elementos adyacentes (como hace el Bubble Sort), el Comb Sort comienza comparando elementos que están `gap` posiciones apartados. A medida que el algoritmo avanza, el `gap` se reduce hasta llegar a 1, momento en el cual se comporta como un Bubble Sort normal.

**Factor de contracción (shrink factor):** El valor recomendado es **1.3**, que es el que ofrece mejor rendimiento en la práctica.

---

### Código en Python

```python
def comb_sort(arr):
    """
    Implementa el algoritmo Comb Sort.
    
    Args:
        arr (list): Lista de números a ordenar (se modifica in-place)
    
    Returns:
        list: La lista ordenada
    """
    n = len(arr)
    gap = n
    shrink_factor = 1.3
    swapped = True
    
    while gap > 1 or swapped:
        # Reducir el gap
        gap = int(gap / shrink_factor)
        if gap < 1:
            gap = 1
            
        swapped = False
        
        # Realizar una pasada con el gap actual
        for i in range(n - gap):
            if arr[i] > arr[i + gap]:
                arr[i], arr[i + gap] = arr[i + gap], arr[i]
                swapped = True
                
    return arr


# ====================== EJEMPLO DE USO ======================

if __name__ == "__main__":
    # Ejemplo de prueba
    numeros = [64, 34, 25, 12, 22, 11, 90, 88, 45, 67, 23, 5]
    
    print("Arreglo original:", numeros)
    comb_sort(numeros)
    print("Arreglo ordenado: ", numeros)
```

**Salida:**
```
Arreglo original: [64, 34, 25, 12, 22, 11, 90, 88, 45, 67, 23, 5]
Arreglo ordenado:  [5, 11, 12, 22, 23, 25, 34, 45, 64, 67, 88, 90]
```

### Complejidad Big O

| Caso              | Complejidad Temporal | Notas |
|-------------------|----------------------|-------|
| **Peor caso**     | `O(n²)`              | Similar al Bubble Sort |
| **Mejor caso**    | `O(n)`               | Cuando el arreglo ya está casi ordenado |
| **Caso promedio** | `O(n² / log n)`      | Mejor que Bubble Sort en la práctica |
| **Espacio**       | `O(1)`               | Ordenamiento in-place |

**Ventajas sobre Bubble Sort:**
- Mucho más rápido en la práctica.
- Elimina rápidamente elementos "tortuga" (elementos pequeños al final).
